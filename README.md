# Plus Egypt | Environmental Consultancy

A modern, responsive, and interactive landing page for **Plus Egypt**, an environmental consultancy and sustainable development firm.

## 🌟 Features

- **Premium UI/UX**: Designed with a sleek, professional, and trustworthy aesthetic suitable for governmental and international partners.
- **Light & Dark Mode**: Fully integrated theme toggler that seamlessly switches between a clean Light Mode and a premium Dark Mode. The user's preference is saved in `localStorage`.
- **Dynamic Interactions**: Features scroll reveal animations, interactive particle backgrounds, and smooth hover effects.
- **Responsive Layout**: Optimized for desktop, tablet, and mobile devices using CSS Grid and Flexbox.
- **Modern Project Grid**: A beautiful grid showcase featuring real client work and environmental impact assessments.

## 🛠️ Technologies Used

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom properties (variables) for theme management, advanced layouts, and modern animations (built with Vanilla CSS for maximum control).
- **Vanilla JavaScript**: Handling theme toggling, scroll events, canvas particles, and DOM interactions.

## 📁 Project Structure

- `index.html` - The main layout and content structure.
- `style.css` - All styling, including the design system, Light/Dark variables, and responsive media queries.
- `script.js` - Application logic for interactive elements.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser to view the site locally. No build tools, package managers, or external dependencies are required.
